# 🌊 Three.js 3D Animated Background

An interactive fullscreen 3D animated background built using Three.js.  
This project creates a smooth wave-like distortion effect on image textures with a responsive modern UI overlay.

---

## ✨ Features

- Fullscreen responsive 3D background
- Wave animation using PlaneGeometry vertices
- Dynamic texture rendering
- Smooth animation loop
- Responsive navigation and text overlay
- Built with Three.js and Parcel
- Lightweight and modern setup

---

## 📸 Preview

- Animated wave distortion
- Fullscreen ocean-style background
- Interactive texture switching

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/your-repo-name.git
```

Go into the project folder:

```bash
cd your-repo-name
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npx parcel index.html
```

---

## 🚀 Build for Production

```bash
npx parcel build index.html
```
